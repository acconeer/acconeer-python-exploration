# Unreleased Changelog

## Unreleased

### Added

### Changed
- Notes about settings show an icon and plain text on a faint tint of their
  color, instead of bold text on an orange or red bar.
- Input fields write numbers with a decimal point, as the rest of the app
  does, whatever the system's locale. A typed comma is taken as one too.
- The Exploration Tool takes on Acconeer's look: its blue, grays, symbol
  and typeface, and outline icons.

### Fixed
- Starting an A2 application with recording enabled no longer fails with
  "Could not start" after a recorded session in another one.
- A value typed next to a logarithmic slider is no longer changed to a nearby
  value.
- A note under a setting no longer flickers while the setting is changed.

### Removed
